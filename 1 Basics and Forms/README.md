# 📝 1 Basics and Forms

## 📚 Is Folder Ka Maqsad
Is folder mein HTML ke basic elements, boilerplate structure aur Forms banana sikhaya gaya hai.

## 🎯 Key Topics Covered
- **HTML Skeleton**: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>` ka basic structure.
- **Forms**: User se data input lene ke liye `<form>` tags.
  - `<input type="text">`
  - Form submission basics
- **Homework**: Homework files bhi is folder mein mojood hain jin par practice ki gayi hai.

## 💡 Practice Instructions
Aap in files ko open kar ke browser mein check kar sakte hain, aur code mein mojood comments se aapko clear samajh aa jayega ke kaunsi line of code kya kaam kar rahi hai.
