# 🚀 Practice HTML 2 - Main Repository

Aap is repository mein HTML ke mukhtalif topics par practice kar sakte hain. Poore project ko properly folders mein taqseem kiya gaya hai taake aap asaani se samajh saken:

## 📁 Folder Structure

1. **`1 Basics and Forms/`**: HTML basics aur Forms ki practice.
2. **`2 Tables/`**: Tables, Rowspan, Colspan, aur Colgroups.
3. **`3 Lists/`**: Ordered, Unordered, aur Nested Lists.
