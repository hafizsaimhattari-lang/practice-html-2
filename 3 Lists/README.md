# 📋 3 Lists in HTML

## 📚 Is Folder Ka Maqsad
HTML mein data ko bullet points ya numbering ki shakal mein dikhane ke liye Lists ka use kiya jata hai. Yeh folder usi ki practice ke liye hai.

## 🎯 Key Topics Covered
- **Unordered Lists (`<ul>`)**: Jin mein bullets ya circles hote hain.
  - `<li>`: List ke har ek item ke liye.
- **Ordered Lists (`<ol>`)**: Jin mein numbering (1, 2, 3), alphabets (A, B, C) ya Roman numerals (i, ii, iii) hote hain.
- **Nested Lists**: Ek list ke andar doosri list banana.
- Images ko lists ke sath use karna (maslan recipe ingredients waghera ke liye).

## 💡 Practice Instructions
Aap list wali files open kar ke unki output dekh sakte hain. Comments read karein taake `<ul>` aur `<ol>` ka farq wazeh ho jaye.
