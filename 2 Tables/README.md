# 📊 2 Tables and Spans

## 📚 Is Folder Ka Maqsad
Is folder ka poora focus HTML Tables, unki styling, aur complex table layouts par hai jahan par multiple rows ya columns ko aapas mein merge kiya jata hai.

## 🎯 Key Topics Covered
- **Basic Tables**: `<table>`, `<tr>`, `<td>`, aur `<th>` tags ka use.
- **Colspan aur Rowspan**: 
  - `colspan="2"`: Ek cell ko horizontal (columns mein) bada karne ke liye.
  - `rowspan="2"`: Ek cell ko vertical (rows mein) merge karne ke liye.
  - Examples: Football scores table, product sales table.
- **Colgroup aur Rowgroup**: 
  - `<colgroup>` aur `<col>`: Poore column ko ek saath target aur style karne ke liye.
  - `<thead>`, `<tbody>`, `<tfoot>`: Jinhein Rowgroup ke alternatives ke tor par jana jata hai, taake table ke head, body, aur footer ko group kiya ja sake.

## 💡 Practice Instructions
Is folder mein bohot si practical exercises aur images mojood hain (jese football scores aur product sales). Code mein comments add kiye gaye hain taake har span aur group ko asaani se samjha ja sake.
